# FrizzQOL

Valheim quality-of-life mods. Each folder is its own mod, ready to publish on GitHub and Thunderstore.

| Folder | GitHub | Thunderstore name | What it does |
| --- | --- | --- | --- |
| FrizzQOL.AlwaysSeason | https://github.com/frizzlebeard/FrizzQOL.AlwaysSeason | FrizzQOL_Always_Season | Seasonal recipes and build pieces stay available all year. |
| FrizzQOL.AreaRepair | https://github.com/frizzlebeard/FrizzQOL.AreaRepair | FrizzQOL_Area_Repair | Hammer repair also fixes nearby pieces. |
| FrizzQOL.BoatControl | https://github.com/frizzlebeard/FrizzQOL.BoatControl | FrizzQOL_Boat_Control | Boat chest size, cargo cap, and hammer removal. |
| FrizzQOL.BrefasveinnBelt | https://github.com/frizzlebeard/FrizzQOL.BrefasveinnBelt | FrizzQOL_Brefasveinn_Belt | Belt that lets portals carry ores and metals. |
| FrizzQOL.BuildFromChest | https://github.com/frizzlebeard/FrizzQOL.BuildFromChest | FrizzQOL_Build_From_Chest | Build with wood and stone from a nearby chest. |
| FrizzQOL.CartControl | https://github.com/frizzlebeard/FrizzQOL.CartControl | FrizzQOL_Cart_Control | Cart storage, pull weight, and durability. |
| FrizzQOL.GameClock | https://github.com/frizzlebeard/FrizzQOL.GameClock | FrizzQOL_Game_Clock | HUD clock, day, weather, and wind. |
| FrizzQOL.MobCap | https://github.com/frizzlebeard/FrizzQOL.MobCap | FrizzQOL_Mob_Cap | Cap creature stars by config and by day. |
| FrizzQOL.NoToolStamina | https://github.com/frizzlebeard/FrizzQOL.NoToolStamina | FrizzQOL_No_Tool_Stamina | Hammer, hoe, and cultivator use no stamina. |
| FrizzQOL.ServerMap | https://github.com/frizzlebeard/FrizzQOL.ServerMap | FrizzQOL_Server_Map | Shared explored map, markers, and building overlay. |
| FrizzQOL.StationRadius | https://github.com/frizzlebeard/FrizzQOL.StationRadius | FrizzQOL_Station_Radius | Per-station build and use radius. |

Copy `Environment.props.example` to `Environment.props` inside a mod before you build it. The `zips` folder has the Thunderstore package for each mod.

## Source

Each mod is its own public repository. The links are in the table. This folder is only the index and the upload zips. Do not upload this parent folder to Thunderstore.
