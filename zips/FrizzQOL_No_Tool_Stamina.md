# FrizzQOL No Tool Stamina

The vanilla hammer, hoe, and cultivator cost no stamina to place, repair, flatten, plant, or remove.

Sprint and other weapons stay vanilla. There is no config file.

## Multiplayer

Install this on every player. A dedicated server does not need it.

## Source

https://github.com/frizzlebeard/FrizzQOL.NoToolStamina

## Install

Install with r2modman or the Thunderstore Mod Manager.

To install by hand, copy `FrizzQOL.NoToolStamina.dll` into `BepInEx/plugins`.

## Requirements

- Valheim
- [BepInExPack for Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/)
